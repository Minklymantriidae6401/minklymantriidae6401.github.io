🤔 What Is Cheshi?

Cheshi is like a photographic memory for your AI conversations. Imagine you talked to an AI assistant (like OpenAI Codex) about a tricky problem last Tuesday. You found a solution. But now, two weeks later, you can't remember exactly what you decided or why.

With Cheshi, that problem disappears. It automatically saves every conversation you have with AI, makes them searchable, and links them to the original code, files, and notes. You can type "why did we choose PostgreSQL last week?" and instantly see the full conversation, the code snippets, and the reasoning behind that choice.

✨ Amazing Features That Will Transform Your Work

🔍 Intelligent Conversation Search

Type any keyword, phrase, or even a vague memory ("that thing about databases") and Cheshi finds the exact conversation. It searches through every word you and the AI exchanged.

📎 Source Links to Everything

Every conversation is connected to the code files, Apple Notes, Git commits, and terminal sessions where it happened. Jump directly from a memory to the original file or note.

🖥️ One Workspace for Everything

Cheshi brings together OpenAI Codex, your code editor, Git worktrees, Ghostty terminals, and Apple Notes into one clean interface. No more switching between five different windows.

🤖 Agent Orchestration

Manage multiple AI agents and conversations effortlessly. Cheshi keeps track of which agent did what, making it easy to review, reuse, or redirect your AI team.

📚 CodeGraph Integration

Explore your codebase visually with CodeGraph. See how files connect, understand dependencies, and find related code instantly.

🗂️ Apple Notes Deep Link

Cheshi integrates with Apple Notes. Your AI conversations can be saved as notes, and your notes become searchable alongside your AI memory.
